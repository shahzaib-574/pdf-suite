# Original API 36 capture evidence

These are the unmodified framebuffer PNGs and original manifest from protected
GitHub Actions screenshot run
[`36566379362`](https://github.com/shahzaib-574/pdf-suite/actions/runs/36566379362),
built from source commit `6b3ead375d7d039b7346452d2043f9d30dd9fcad`.

The active store PNGs are losslessly decoded and saved as opaque 24-bit RGB for
Google Play. `store-assets/screenshots/CI_CAPTURE_SOURCE.json` records each active
normalized PNG hash as `sha256` and preserves this archive's original framebuffer
PNG hash as `sourceFramebufferPngSha256`. The scan-editor frame is retained here
as original evidence but was rejected from the selected store set because its
page did not render visibly.
