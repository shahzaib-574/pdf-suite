What the website uses

The current Ream website code does not set HTTP cookies, load analytics trackers, advertising scripts or tracking pixels. It does use localStorage and IndexedDB in your browser profile. These technologies are not HTTP cookies, but rules about storing or accessing information on a device can apply to them too.

Ream's current browser stores are not transmitted to a Ream backend. This does not rule out technical data being received by the website host. Hostinger is the selected hosting provider; enabled CDN/security services, server-set cookies or other host features have not yet been verified. The deployment must be checked before the final notice is published.

Appearance preference — localStorage: pdf.theme
Stores light, dark or system appearance when you choose a theme. Read on later visits to restore that choice. Persists until changed or removed using browser site-data controls.
Motion preference — localStorage: pdf.reducedMotion
Stores your reduced-motion preference when you change it in Preferences. The site also reads your operating system's reduced-motion setting. Stored preference persists until changed or cleared.
Tool availability flag — localStorage: pdf.pro
A local compatibility flag initialized by the current app to keep tools unlocked. It is not a purchase record, subscription, account identifier or advertising identifier. Persists until browser site data is cleared; the current app can recreate it on the next visit.
Local file library — IndexedDB: pdf.library.v2 and pdf.file.<id>
Stores recent-file metadata (such as name, size, file type, tool and creation time) and saved file bytes for local reopening. Legacy installations may also contain pdf.recents, migrated to the current library. The library is limited to 200 items and 512 MB, subject to browser quota. Copies remain until you delete or clear them or the browser removes site data; they are not a guaranteed backup.
Resumable scan draft — IndexedDB: ream-scan-draft-v1 and ream-scan-draft-files-v1
If scanner functionality is used, these records can retain an unfinished draft, edits and image bytes for resuming on this device. The website's public tool catalog does not list Scan, but its shared scanner route can be opened. Clearing the recent-file library alone does not clear a scan draft. Use Discard in the scanner and confirm Discard, or clear all site data in your browser. Reset only resets page edits; it does not delete the whole draft.
Downloaded assets and temporary data
Your browser can cache website files, fonts, PDF-rendering resources and OCR language assets under its normal caching rules. OCR may also cache language data locally in IndexedDB. Processing files also uses temporary browser memory while a tool or reader is open. Cache lifetime depends on browser and hosting settings, not a fixed retention promise from Ream.

How to remove local data

  1. To remove one library item, open Your files and delete it.
  2. To remove the current recent-file library, open Preferences, find Privacy & storage, select Clear recent files, then confirm with Clear files.
  3. To remove all data for this site, use your browser's site-data or storage settings for the Ream website address. This also removes stored preferences, cached data and any draft records. Labels differ between browsers.

Export anything you want to keep first. Deleting local data does not remove copies saved to Downloads, another folder, email, a sharing app or another device. Clearing data in one browser profile does not clear another profile.

Blocking storage and consent

You can restrict browser storage. Preferences, local recents and resumable drafts may then be unavailable; browser quota or private-browsing mode can also affect saving. Ream's tools should not be treated as a durable storage service.

No advertising or analytics consent banner has been added to the current website because Ream's code does not include those features. That is not a legal conclusion that all current storage is consent-exempt. The operator must assess each purpose, the user-requested functionality, automatic writes and applicable storage-access rules before public release, and add appropriate choices where required. Any future non-essential tracking must be reviewed and gated before it is activated.

Website and Android are different

The Android app's advertising identifiers, AdMob and privacy-choice forms are outside this website notice. Read the Android privacy policy for those features. We will update the final website inventory if its storage or services change.
