#### Design Specificity Verdict

**Start here.** Authored chrome, category-interchangeable product.

**LLM assessment**: The dark/light system (folded mark, violet feature card, inset shadows, teal "On-device" pill) is designed for Ream, not a Vite default. Once you leave the hero, the app is a 13-tile PDF utility like Smallpdf / iLovePDF: chips, Lucide tiles, dashed file well, disabled primary. Catalog groups (`everyday` / `pages` / `lock`) never appear. "Smart PDF to Word" is the only distinctive promise, then the same job is labeled Extract in the tab bar and PDF → Word in the grid.

**Deterministic scan**: CLI `detect.mjs` on `src/App.tsx`, `src/screens`, `src/components`, and CSS exited 0 with `[]` (markup regex only). Live overlay on five routes found 40 / 11 / 13 / 10 / 11 anti-patterns. Verified: 9px Advanced labels, 10.5px nav labels, thin-border + 20–34px shadows, kicker-above-heading eyebrows, feature-card white-on-`#7665ef` at 4.3:1, extreme negative tracking on the home H1, long PDF→Word note. False positives: skip-link padding, hidden HUD marquee, computed Roboto, leftover overlay copy.

**Visual overlays**: Overlay injection succeeded in Assessment B's tab (`tab_4`) and was cleaned up. This review tab (`tab_2`) was used for the live walkthrough and does not currently show overlays.

#### Overall Impression

The shell looks store-ready. The first job does not. Home, Recents empty, Settings, and light/dark theming are the strongest screens in the product. Tool flows then drop into a dashed well, a huge empty band, and a lavender disabled button that still looks tappable. The biggest opportunity is collapsing the conversion story to one name and making the empty tool screen teach the next tap.

#### What's Working

1. **Privacy is visual, not a footer.** Eyebrow, teal On-device pill, well hints, Settings shield copy, and no-account language all say the same thing.
2. **Theme and empty Recents are finished.** Light/dark/system, reduced-motion, inline clear-confirm, and "No files yet / Browse tools" are the screens that feel like a real app.
3. **Hit targets and navigation landmarks are mostly right.** 48px chips, labeled tabs, skip-to-nav, regions, and a left rail at desktop width.

#### Priority Issues

- **[P1] One conversion, three names**
  - **Why it matters**: Hero "Smart PDF to Word", tab "Extract", tile "PDF → Word". First-timers cannot tell which control is the job.
  - **Fix**: Pick one name. Make the tab, hero, and tile identical. Hide or demote the duplicate doors.
  - **Suggested command**: `$impeccable clarify` (and `$impeccable distill` if the tab should go)

- **[P1] Advanced badges with no paywall**
  - **Why it matters**: Split, Compress, Organize, Watermark, Page numbers, Protect, and PDF → Images all say ADVANCED. They all work. Settings has no Pro control. Intern copy "Pro is off (dev toggle)" is still in the tool screen.
  - **Fix**: Remove badges until Play Billing ships, or make them mean something.
  - **Suggested command**: `$impeccable clarify`

- **[P1] Tool empty states are unfinished rooms**
  - **Why it matters**: Merge / Protect / PDF → Word spend half the phone on blank canvas. Disabled "Merge PDFs" / "Protect PDF" / "Convert to Word" look like faded primaries (opacity 0.45), not "add a file first." Split options appear before a PDF exists.
  - **Fix**: Put the pick action in the void. State limits before pick. Style disabled as clearly inactive. Hide Adjust until a file is present.
  - **Suggested command**: `$impeccable layout` / `$impeccable onboard`

- **[P1] Result and Viewer empty states**
  - **Why it matters**: Direct `#/result` says "Nothing to show." plus a vague "New". Recents already proves you know how to do empty states.
  - **Fix**: Match Recents: icon, one sentence, one recovery action ("Choose a tool" / "Open a PDF").
  - **Suggested command**: `$impeccable harden`

- **[P2] Search "word" matches Protect**
  - **Why it matters**: Substring match on "password" → "word". Jordan searching for Word conversion gets a lock tool.
  - **Fix**: Tokenize search; match whole words or title-first.
  - **Suggested command**: `$impeccable clarify`

- **[P2] Duplicate chrome and tiny type**
  - **Why it matters**: Header gear and Settings tab do the same thing. Nav labels are 10.5px; Advanced is 9px. Feature-card white-on-purple is 4.3:1 (WCAG AA miss by 0.2). Scan tab opens the OS picker instead of the Scan tool.
  - **Fix**: Drop header Settings on Home. Bump nav to 12px. Darken the feature-card type or the gradient stop. Point Scan tab at `#/tool/scan`.
  - **Suggested command**: `$impeccable adapt` / `$impeccable typeset`

#### Persona Red Flags

**Jordan (first-timer)**: Lands on 13 tiles + a featured card + four filters + five tabs. Does not know whether to tap Smart PDF to Word, Extract, or PDF → Word. ADVANCED on most tiles looks locked. Search "word" also hits Protect.

**Casey (mobile, one-handed)**: Primary job is above the fold, good. Last tool row sits under the tab bar. Scan in the thumb zone opens a system sheet, not the Scan screen. Header gear is in the unreachable top corner and duplicates the tab. Tool CTA fights the tab bar.

**Riley (edge cases)**: Result/Viewer dead-ends if you deep-link or lose in-memory job state. Merge's free 2-file cap is only stated after pick. Disabled buttons swallow taps (`pointer-events: none`) so there is no inline "add a file" error. English-only OCR is a footnote, not a gate.

#### Cognitive load

Checklist failures: competing primary actions; All-by-default 13-tile wall; Split/Protect options before a file; three names for one conversion; dual Settings and dual Scan. Home All is well above the 4-option working-memory limit (13 tiles + featured card + 4 filters + 5 tabs).

#### Emotional journey

Peak: first Home — mark, privacy eyebrow, gradient conversion card. Settings and Recents empty keep that trust. Valley: any tool with a dashed well and a disabled lavender bar. Worst: Result "Nothing to show." End of a first session is a waiting room, not a finished file.

#### Minor Observations

- See all on Home Recents when the list is empty is a ghost action.
- Desktop feature card stretches to ~960×92, a thin purple ribbon.
- Reduce-motion switch is 46×28, under 44px height.
- Protect password is `type="password"` with `autocomplete="new-password"` but has no confirm or show/hide.
- Light theme is as considered as dark; keep both.
- Skip-to-nav exists and is correctly off-screen.

#### Questions to Consider

- If Ream is a private workspace, why is the first screen a 13-item catalog?
- Would anyone miss Extract in the tab bar if Smart PDF to Word were the only conversion door?
- What does Advanced mean to someone who just needs two PDFs stuck together?
